# 12D 血液科病房常用處方速查 (Hematology Ward Common Orders)

整理自 12D 血液科病房常用處方（2026.11），提供快速檢索、一鍵複製醫囑、劑量試算與抗生素封存療法（ALT）對照：

- **12D 常用處方**：痔瘡（坐浴／藥膏）、漱口水、口腔止痛噴霧、口內膏、止嗝、輸血前預防、DLC／Urokinase／出院管路 LOCK、G-CSF（含短效 5 mcg/kg 劑量試算）
- **突破性噁心嘔吐（Breakthrough N/V）**：健保與自費止吐針劑及口服／口溶藥物
- **入院常用 & 藥物濃度監測（TDM）**：VRE swab、血糖 `[$]`、血氧、CBC/DC 注意事項；Cyclosporin A、Tacrolimus、Methotrexate、自費 Antifungal level（`000R5042`）開立途徑與規則
- **Ribavirin for RSV**：互動式劑量計算機與 UCSF IDMP 非透析／間歇性透析／連續性透析對照表
- **12D 常用 Antibiotic Lock 處方與泡法**：8 種常用抗生素 ALT 稀釋泡法（血液科因血小板低均不加 Heparin）
- **CRI 評估與治療流程 & ALT 文獻對照**：CRI 決策流程圖、表一 ALT 濃度建議、感控雜誌（2013;23:88-94）與 UpToDate CRBSI Lock 對照表
