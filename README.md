# 血液科病房常用處方速查 (Hematology Ward Common Orders)

整理血液科病房常用處方（2026.11），提供快速檢索、劑量試算與抗生素封存療法（ALT）指引對照：

- **病房常用處方**：痔瘡（坐浴／藥膏）、漱口水、口腔止痛噴霧、口內膏、止嗝、輸血前預防、DLC／Urokinase／出院管路 LOCK、G-CSF
- **突破性噁心嘔吐（Breakthrough N/V）**：健保與自費止吐針劑及口服／口溶藥物
- **入院常用 & 藥物濃度監測（TDM）**：VRE swab、血糖 `[$]`、血氧、CBC/DC 注意事項；Cyclosporin A、Tacrolimus、Methotrexate、自費 Antifungal level（`000R5042`）開立途徑與規則
- **Ribavirin for RSV**：互動式劑量計算機與 UCSF IDMP 非透析／間歇性透析／連續性透析對照表
- **常用 Antibiotic Lock 處方與泡法**：8 種常用抗生素 ALT 稀釋泡法（血液科因血小板低均不加 Heparin）
- **抗生素封存療法（ALT）使用建議 & CRI 流程**：整合臺大醫院感染科、藥劑部 ALT 使用建議（文件編號 15660-2-000004），含定義與移除導管時機、體積與操作注意事項、CRI 評估流程圖（含 *Enterococcus* spp.）、表一濃度建議、附件一泡製步驟、感控雜誌（2013;23:88-94）、UpToDate 對照表與 13 篇參考文獻
